# وثائق مشروع «هُدًى»

> **[أُضيف عند إعادة تنظيم الوثائق]** هذا فهرس فقط. نُقلت الوثائق القديمة إلى مجلدات بحسب الموضوع، ولكل ملف موضوع واحد. لم يتغير نص أي فقرة أو جدول أو قائمة؛ الذي تغير: سطر تعريفي في رأس كل ملف مقسوم، ومستوى بعض العناوين، وتحويل الإحالات (أرقام الأسطر والأقسام وأسماء الملفات) إلى روابط.

## السجلان

- [`decisions.md`](decisions.md): **سجل القرارات**، المرجع الوحيد لحالة كل قرار: ساري، أو مفتوح، أو للتأكيد، أو مستبدل.
- [`ideas.md`](ideas.md): **صندوق الأفكار**. تُكتب فيه كل فكرة تظهر في النقاش حتى يُقرر فيها.
