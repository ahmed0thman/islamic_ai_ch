(ب) وصف مأخوذ من الملفات في 5 أكتوبر 2026، لتكمل أي جلسة جديدة بلا سياق سابق. لا يعتمد شيئًا ولا يغيّر قرارًا. المرجع للقرارات `docs/decisions.md`، وللمهمة `docs/08-open/tasks/m-006-three-day-plan.md`.

**الجوهر:** قارئ غير متخصص يقرأ شرح السورة نصًّا منسوجًا بأربع درجات (لمحة 0، فهم 1، تدبر 2، تعمق 3). الذكاء الاصطناعي لا يولّد آية ولا معنى ولا يحكم على رواية: كل دعوى يحملها سجل متحقق منه يقتبس مصدره، وبعدها علامة تفتح المصدر.

## 1. الخريطة

```
.cache/sources/ -> .cache/index/sources.sqlite -> [الباني: بحث -> مسودة سجلات -> سجلات -> نسيج]
  -> بوابات -> (فشل: إصلاح، جولتان) -> تصدير -> مراجع مستقل -> (ملاحظات: إصلاح بعد المراجعة -> بوابات -> تصدير -> مراجعة ثانية)
  -> content/export/ -> app/src/content/ -> التطبيق
```

الترتيب في الكود: التصدير يقع بعد نجاح البوابات وقبل المراجعة، ويُعاد بعد كل إصلاح بعد المراجعة.

| المرحلة | الملف | المدخل -> المخرج | المنفذ |
|---|---|---|---|
| جلب الكتب | `tools/fetch_shamela.py` | خادم الشاملة -> `.cache/sources/shamela/books/<id>/pages/*.json` | سكربت، بلا نموذج |
| الفهرس | `tools/build_index.py` | `.cache/sources/**` (الشاملة، سورة بيديا، موسوعة القرآن، موسوعة الأحاديث) -> `.cache/index/sources.sqlite` (FTS5) | سكربت |
| البحث | `tools/retrieve.py` | الفهرس -> نص حرفي بموضعه (`--ayah`، `--text`، `--id`) | سكربت، يستدعيه الباني |
| مسودة السجلات | `.cache/records/N/draft.v2.json` | البحث -> مسودة بشكل `DRAFT_FORMAT` | الباني: نموذج، ممر `claude:think-pro` (أوبس، كلود ماكس)، بتكليف `prompts/build-surah.ar.md`، بسكربت مولّد يحفظه في مجلد السورة |
| بناء السجلات | `.cache/records/108/build_records_v2.py` | المسودة + المصادر على القرص -> `.cache/records/N/records.v2.json` | سكربت (يحسب التحقق وأذون البناء والعرض) |
| النسيج | `content/nasij/N.json` | السجلات -> نسيج بأربع درجات، و`held` لما لا يحمله سجل | الباني، بسكربت مولّد يقتطع الاقتباسات آليًّا |
| البوابات | `run_surah.py` (دالة `gates`) | الملفان أعلاه -> نجاح أو سطور فشل | سكربتات: `check_v2.py` و`export_content.py --check-only` |
| الإصلاح بعد فشل البوابات | `prompts/fix-surah.ar.md` | ناتج الفحص حرفيًّا -> إصلاح الملفين | الباني نفسه، حتى جولتين |
| التصدير | `tools/export_content.py` | السجلات + النسيج + المصحف -> `content/export/surah-N.json` و`index.json` و`.cache/records/N/review.md` | سكربت |
| المراجع المستقل | `prompts/review-surah.en.md` | الملفان + الفهرس (قراءة فقط) -> `.cache/pipeline/N/review.json` (آخر كتلة JSON) | نموذج غير الباني: ممر `codex:review` (أسترا) |
| الإصلاح بعد المراجعة | `prompts/fix-review.ar.md` | ملاحظات المراجع (بلا ملاحظات الحالة العامة) -> إصلاح | الباني، جولة واحدة افتراضًا |
| إعادة النسج | `prompts/weave-surah.ar.md` | سورة مبنية -> درجات 0 و1 و2 بصوت النسيج | نموذج، **يدويًّا**: غير موصول بالمشغّل |
| المزامنة والعرض | `app/scripts/sync-content.mjs`، `app/src/lib/content.ts` | `content/export/*.json` و`ui.ar.json` -> `app/src/content/` -> صفحات ثابتة | سكربت Node، والتطبيق Next.js بتصدير ثابت |

المشغّل `tools/pipeline/run_surah.py` يدير الحلقة كلها بعد الجلب والفهرسة، ويكتب `.cache/pipeline/N/eval.json` (الحالة، الأزمنة، الجولات، العدّ، الدرجات). وهو يرسل التكليفات عبر `~/.agents/skills/{claude,codex}-delegate/scripts/relay.mjs` بممرات `.delegate/config.json`، ولا يقبل إلا ممرات كلود وكودكس.

## 2. الأوامر (من جذر المستودع)

```bash

# التطبيق (من app/)
pnpm sync-content        # ينسخ ui.ar.json وexport/*.json إلى app/src/content ويولّد manifest
pnpm dev                 # أو pnpm build (فيه prebuild للمزامنة، وpostbuild للفحص والعمل بلا اتصال)
```

## 4. الضمانات ومن يفحص

**فحوص السجلات (`check_v2.py`، رمز خروج 1 عند فشل صلب):** S1 مفاتيح الآيات في المصحف. S2 لا نص آية بين ﴿﴾ في الدعوى إلا من آيات السجل. S3 دليل الآية بلا اقتباس مخزَّن. S4 لكل سجل دليل، والهداية دليلها معزو. S5 مصدر معتمد وموضع للقارئ، والكتاب مكتمل السحب. S6 حقول الحكم المنقول وحالته، ولا مرفوع بلا حكم. S7 لا رواية من كتب اللغة والبلاغة. S8 لا بناء بحكم مؤلف مصدر لا يستوفي ق-055. S9 اتساق الإذن والشارة والدرجة. S10 قوة الربط. S11 `built_on` لا يشير إلا إلى «نعم». S12 الاقتباس بلفظه في قطعته (ولا يتجاوز 400 حرف)، ولفظ الحكم موجود. S13 تحقق النقل عن الواسطة. S14 القائل ليس أحد الشرّاح الأربعة (ق-061). S15 نص اللوحة. S16 إذن البناء يساوي المحسوب. S17 اتجاه الحكم يسنده لفظ صريح. S18 إذن العرض ومرتبة المراجعة. N19 حقلا `term` و`plain_meaning`.

**بوابات التصدير (`export_content.py`، ترفض السورة كلها عند أي فشل وتحفظ الموجود):**
- C1: مفاتيح الآيات موجودة. C2: لا نص قرآني في كلام النظام (نافذة أربع كلمات، أو ﴿﴾).
- C3: السجلات المشار إليها موجودة. C4: لكل فقرة علامة، والعنوان ينتهي بعلامة.
- C5: كل دعوى بإذن بناء «نعم». C6: فقرات النقل والاقتباسات حرفية، وإذن العرض «نعم».
- C7: درجة السجل الدنيا لا تتجاوز درجة الفقرة. C8: ما رُفض عرضه لا يدخل.
- C9: أربع درجات غير فارغة. C10: ما في `held` لا يُعرض.
- C11: عناوين الوقفات نص نظام من 1 إلى 8 كلمات. C12: لكل وقفة آياتها. C13: المقاطع تغطي السورة بلا فجوة ولا تداخل. C14: اثنتا عشرة وقفة على الأكثر في الدرجة.
- أُحكمت في 5 أكتوبر: C6 فقرة النقل فيها اقتباس، وC13 سجلات المقاطع بإذن بناء «نعم». و**W12 تنبيه لا يرفض التصدير:** آية الوقفة الصريحة ليست من آيات سجلاتها (ست سور مبنية تقع فيه: 78 و80 و83 و96 و108 و111).

**المراجع المستقل** (أسترا بقراءة فقط، لا يراجع الباني نفسه): يقرأ كل جمل الدرجات 0 إلى 2، وعناوين التعمق ونصف بنوده على الأقل، وكل عنوان وقفة ومقطع ومصطلح ورواية «نعم»؛ يحكم على الدعم والنسبة وأمانة النقل والروايات والمصحف وجذب القارئ، ويرجع JSON بدرجات 0 إلى 5 وحكم (`ship` و`fix-then-ship` و`do-not-ship`) وملاحظات (`critical/major/minor`). ملاحظة `review-status` (السجلات بلا مراجعة بشرية) لا تُرسل للباني.

**الناقد** (`.claude/agents/critic.md`): قراءة فقط، عشر ملاحظات بأدلتها على الأكثر، لا يخالف القرارات. يُستدعى عند نقاط التوقف (بعد دفعة سور، أو مجموعة مراحل واجهة، أو تغيير منهج، أو قبل ما يخرج للخارج) لا بعد كل تغيير. وما بناه أوبس ينقده أسترا (ممر `debate`) (ج). فيبل لا يُستدعى إلا بطلب صريح (ق-069).

## 6. الناقص والهش

1. **إعادة النسج خارج المشغّل:** `run_surah.brief()` لا يعرف مرحلة `weave`، فلا أمر مكتوب لها (لم أجد). وسور 78 و83 و98 و110 صوتها القديم (نقل ونسبة) بحسب م-006. والضحى وحدها أُعيد نسجها (ج، ومثالها لم يرد عليه صاحب الفكرة).
2. **عقد الصوت ناقص:** لا قطعة `frame` ولا `example` في العقد؛ وC4 يكتفي بعلامة واحدة في الفقرة فلا يُفحص كل جملة، والمراجع وحده يمسك الدعوى المتنكرة. ونافذة C2 أربع كلمات فيفوتها الأقصر.
3. **الاعتماد على مسار خاص:** البوابات والتكليفات تستدعي `.cache/records/108/` بالمسار، وهو غير مُتتبَّع في git. ولا نسخة احتياطية له إلا مجلدات `backup-before-*`.
4. **المراجع واحد وحصته تنفد:** `lane_command` يرفض ممرات `agy`، فلا `review-gemini` ولا `think` في المشغّل. نفدت حصة أسترا فبقيت ست سور بلا مراجعة.
5. **الروايات والسيرة:** البخاري ومسلم لم يُجلبا، فلا إعادة فتح من الأصل. وخبر السيرة المحمول على قول عالم بلا حكم يُحجز احتياطًا (الحسم لصاحب الفكرة أو متخصص). ورواية «التحرير والتنوير» بلا تخريج فلا تُؤخذ.
6. **سكربتات السور الخاصة هشة:** إعادة تشغيل `gen_draft_93.py` أو `make_draft_111.py` أو `build_records.py` القديم تمحو سجلات النبذات والمصطلحات. والكوثر بُنيت من النسخة الأولى (`V1_OVERLAY`).
7. **الاسترجاع بسيط:** بحث نصي حرفي على FTS5 بعربية مطبَّعة، بلا متجهات ولا إعادة ترتيب ولا مجموعة تقييم. وتصميم ترقية (هجين ومتجهات) طُلب في `.cache/delegate/m-006-rag-design/` (جدول التشغيل: «يعمل»)؛ لم أقرأ ناتجه، ولم أجد تنفيذًا له في `tools/`.
8. **لم أجد:** سكربت جلب سورة بيديا وموسوعة القرآن وموسوعة الأحاديث (لا يوجد في `tools/` إلا جلب الشاملة)؛ ولا أمرًا لنشر التطبيق على استضافة. وميزة «اسأل» (`HUDA_ASK=1`) لم تُجرَّب بنموذج حقيقي.
