# 8.2 المعمل: ما ينتج النسيج قبل أن يراه القارئ

- خريطة المعرفة، وقائمة فحص لكل مقطع عبر كل العائلات ([القسم 6](knowledge-families.md#6-الحصر-الأولي-لعائلات-المعرفة) من وثيقة الرؤية).
- طريقة البحث في كل فرع.
- سياسة المصادر: لكل عائلة مصادرها المعتمدة، وشروط قبولها، وحقوق استخدامها.
- التحقق من الدعاوى **والروابط**، ومنه اتساق المعنى بين درجات العمق.
- مراجعة المتخصص.
- اختبار النقل إلى سور مختلفة الطبيعة.

المهام 1–3 في [`MAX_TASKS.md`](../08-open/max-tasks.md) تبني هذه الطبقة.
