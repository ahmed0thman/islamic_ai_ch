# نموذج التسجيل

## ما هو متاح علنًا: إنشاء الحساب

رابط «التسجيل في التحدي» يحوّل إلى [`/register`](https://islamicaich.org/register)، وهو نموذج **إنشاء حساب شخصي** فقط. حقوله كما في مصدر الصفحة (25 سبتمبر 2026):

| الحقل | النوع |
|---|---|
| الاسم الكامل | نص |
| تاريخ الميلاد | تاريخ |
| البريد الإلكتروني | بريد |
| الجوال | هاتف |
| الجنس | قائمة |
| الجنسية | قائمة |
| دولة الإقامة | قائمة |
| مدينة الإقامة | نص |
| كلمة المرور وتأكيدها | كلمة مرور |
| الموافقة على الشروط | مربع اختيار |

لا يظهر في مصدر الصفحة حد للحروف في أي حقل.

## ما لم يُجلب: نموذج المشروع

أسئلة المشروع (المشكلة، والمستفيد، ودور التقنية، ومؤشر النجاح، ومصادر المحتوى، وخطة البناء، بحسب الدليل) تظهر **بعد تسجيل الدخول**. لم تُنسخ بعد.

**المطلوب من صاحب الحساب:** بعد تسجيل الدخول، انسخ هنا نص كل سؤال وحقل في نموذج المشروع، مع حد الحروف إن ظهر (غالبًا تحت الحقل أو عند الكتابة فيه). منها تُصاغ الإجابات من وثيقة الرؤية قبل الإغلاق يوم 29 سبتمبر.
