# 5. المعمار المعرفي المبدئي

المقترح التقني الذي طرحه صاحب الفكرة هو تجميع مصادر عربية معتمدة وبناء نظام استرجاع معزز بالتوليد (**RAG**) عليها. لكن وظيفة النظام أكبر من إحضار مقاطع متشابهة للسؤال: يجب أن ينظم الدعاوى وروابطها، ويميز نوع كل دليل وحالته، ويقدم للقارئ شرحًا يمكن تتبعه والتحقق منه. شكل قاعدة البيانات، ونموذج العلاقات، وآلية توليد الشرح **لم تُحسم بعد**. أما الواجهة فحُسم مبدؤها دون تفاصيلها: طبقة عرض توليدية بمكونات ثابتة، منفصلة عن خط المعالجة ولا تولّد معلومة (انظر «طبقات المنتج وأولوياتها» في [القسم 4](../06-product/product-layers.md#طبقات-المنتج-وأولوياتها)).

تصور أولي لتدفق المعرفة، يحتاج البحث والمراجعة:

```text
مصادر منتقاة ← استخراج معلومات موثقة ← التحقق وتصنيف الدعاوى والخلاف
             ← ربط المعاني والأدلة في خريطة علاقات
             ← صياغة مسار شرح مترابط ومناسب للقارئ
             ← إسناد ومراجعة واختبار فهم القارئ
```

## سجل لكل معلومة تدخل الشرح

نحتاج، كتصور منهجي مبدئي، إلى حفظ: نص المعلومة أو الدعوى؛ السورة والموضع؛ نوعها العلمي؛ المصدر وموضعه الدقيق؛ طبيعة الدليل وحالة ثبوته؛ أي خلاف معتبر؛ صلتها بالدعاوى الأخرى؛ سبب أهميتها للفهم؛ حالة مراجعتها البشرية؛ وطريقة عرضها للقارئ. هذه **متطلبات بحث وتصميم مقترحة**، وليست مخطط بيانات تقنيًا معتمدًا بعد.
